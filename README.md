# Тестовое задание для рассчета возвраста на основе поля дня рождения

Сервис автоматически рассчитывает возраст контакта в amoCRM на основании даты рождения и записывает результат в пользовательское поле "Возраст".

## Как работает

1. amoCRM отправляет webhook при создании или обновлении контакта.
2. Сервис получает данные контакта.
3. Из пользовательского поля "Дата рождения" извлекается дата рождения.
4. Рассчитывается полный возраст в годах.
5. Полученное значение записывается в пользовательское поле "Возраст".


## Переменные окружения

```env
AMO_DOMAIN=
AMO_CLIENT_ID=
AMO_ACCESS_TOKEN=
AMO_CLIENT_SECRET=
AMO_REDIRECT_URI=
AMO_AUTH_CODE=
AMO_BIRTHDAY_FIELD=
AMO_AGE_FIELD=
```
